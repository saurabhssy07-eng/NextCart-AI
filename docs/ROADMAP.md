# NextCart AI Roadmap

## ✅ Completed Milestones
- **Milestone 1:** Project foundation & GitHub repository
- **Milestone 2:** Database & APIs (MongoDB Atlas)
- **Milestone 3:** Authentication (JWT + Refresh Tokens, Email verification)
- **Milestone 4:** User Management (Profile, Addresses, Wishlist, Orders preview)
- **Milestone 4.5:** UI Foundation (Design System, Framer Motion, Responsive UX)
- **Phase 5.1:** Product Variants Schema & API
- **Phase 5.1.5:** Product Experience Polish

---

## 🚀 Phase 5: Commerce Engine (Highest Priority)
This phase focuses on the core e-commerce workflow and is broken into 2-4 hour chunks.

### Phase 5.2: Product Images & Gallery (Next Focus)
* [ ] Multiple images per product.
* [ ] Zoom-on-hover functionality.
* [ ] Grid/slider layouts for images.
- **5.3 Reviews:** Verified purchase badges, image reviews, likes/replies, rating distribution.
- **5.4 Search:** Autocomplete, suggestions, typo tolerance, recent/popular searches.
- **5.5 Inventory:** Stock tracking, reserved stock, low stock warning, out of stock, preorder.
- **5.6 Coupons:** Percentage/fixed amount, free shipping, expiry, usage limits, minimum purchase.
- **5.7 Recently Viewed:** Cross-session tracking, recommendations based on history.
- **5.8 Product Comparison:** Side-by-side spec comparison.
